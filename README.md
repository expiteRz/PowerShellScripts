`A repo managing PowerShell scripts for Mario Kart Wii modding`

## Requirements

- PowerShell 7.0 or newer (All scripts tested on 7.7.0)

## Scripts

- EasyMakeFastBRSTM.ps1 &mdash; Just generate a fast BRSTM. Currently supports 44100 and 48000 sample rates
- GetBMGFromPulsar.ps1 &mdash; Extract and (optionally) decode BMG data from Config.pul
